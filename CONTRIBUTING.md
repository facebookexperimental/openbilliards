# Contributing to OpenBilliards

OpenBilliards is developed in an internal repository. This public repository
receives curated snapshot releases rather than day-to-day commits, so the
code here may trail internal development.

## Pull requests

We are currently **not able to accept external pull requests** — changes
land here through periodic snapshot syncs from the internal repository, and
maintainer bandwidth goes into that pipeline. Pull requests will be read for
their ideas but closed without merging. The most effective way to influence
the project is a detailed issue.

Should we accept direct contributions in the future, a completed Meta
Contributor License Agreement (<https://code.facebook.com/cla>) will be
required.

## Issues

Bug reports and feature requests are welcome and genuinely drive
development — incoming issues become evaluation workloads for the agentic
development pipeline that builds this project. Please make reports
reproducible: the in-app bug reporter (Settings → Report a bug) produces a
diagnostic JSON bundle that captures versions, the judgment ledger, and the
scenario needed to replay a shot deterministically.

## Security

Meta has a [bounty program](https://bugbounty.meta.com/) for the safe
disclosure of security bugs. In those cases, please go through the process
outlined on that page and do not file a public issue.
