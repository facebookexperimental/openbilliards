# Figures — slots F0–F14

`F0.pdf` … `F14.pdf` are the manuscript's figures; `\figstub` in
`main.tex` includes each one automatically (`\IfFileExists`) and typesets
a framed placeholder for a missing file.

Every PDF is authored at its declared final width (7.0 in / 3.5 in,
≥ 7 pt text) and included at natural size, so printed text size equals
authored size.

Namespace note: slots F0–F14 ≠ experiment IDs F1–F3.

The PDFs were generated from the study's pinned experiment outputs by the
paper's figure script, which belongs to its artifact bundle and is not
part of the public source release; they are committed here as manuscript
inputs.
