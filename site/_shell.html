02 — Code voice

Duotone wells

// rack, break, and read the table — sample
import { Table } from "@openbilliards/sdk";

const table = Table.rack("9-ball", { seed: 42 });
const events = table.strike({ v: 6.2, cut: 0.31 });
console.log(events.at(-1).state);

Inline names like Table.rack take chalk; captions sit in the muted body voice.
