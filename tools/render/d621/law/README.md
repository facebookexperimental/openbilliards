renderer and measurement tools. Purchased-model inputs stay in quarantine; the law
records scalar evidence, source digests and explicit rulings.

## The accepted f ruling binds to f's input meshes

f reads the exact-B sections of `dm-cushion-0..5` and `dm-railtop-0..5`
(`cushion_profile_621.py` `ours_rails`). The accepted f exception binds to those
twelve meshes at 7, 8 and 9 ft, not to the bytes of `web/scene/table.js`
(maintainer ruling 2026-10-19, option C). Every change to f's input meshes
re-runs f. A table.js edit that leaves those meshes byte-identical does not.

`cushion_law_621.json` → `ruled_red_rows.f_p90.characterized_inputs` records
three things:
- the characterized commit;
- the pinned node version;
- the sha256 of each input mesh (Float64 world positions + Uint32 indices, the
  gate's `mesh_fence` formula).

`plan/f_input_guard_621.mjs` enforces it on every pull request (ci.yml job
`d621-f-input-guard`, which pins the node version). It builds the three tables at
the characterized commit and at HEAD, each from its own tree in its own node
process. It fails by name on:
- a changed, missing or extra input mesh;
- a law record that no longer equals its commit.

`--selftest` proves the guard on three plants: a moved coordinate, a
comment-only edit, and a removed mesh.

When the guard fails because f's inputs really changed:
1. Re-run the deciding f measurement on the final served renderer.
2. Record the complete measured p90, the unchanged threshold, the sample count
   and the measurement receipt.
3. In the same commit, re-record `characterized_inputs`.
   `f_input_guard_621.mjs --record` prints HEAD's digests. Set `commit` to the
   commit that carries them, and `node` to the CI runtime.
4. Preserve the previous binding in the ruling's `history` list. Explain why the
   inputs changed and why the accepted exception still applies.

The `cushion_f_input_binding` row always decides in the Diamond cushion section.
It compares the law's input-mesh digests with the archive gate's app dumps. A
missing, extra or different input mesh fails by name, even if f's numerical row
passes. A matching binding alone does not accept an incomplete sample set or
waive any other red row. The accepted f exception remains `RED-BY-LAW`, with its
raw residual, threshold and retained CU-08 crease visible. Use the Diamond
HTTP/CDP band 9520/9535 for this lane's browser runs.
